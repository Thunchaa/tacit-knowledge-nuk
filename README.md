# Tacit Knowledge Elicitation — นัก

## Agent Prompt

Conduct a Tacit Knowledge Elicitation Interview.

Ask me one question at a time to uncover how I know what I know.
Focus on web UX/UI design, desktop and mobile design, color,
image selection, and layout.

Ask follow-up questions based on my answers.
At the end, summarize the 10 most important elements of a good website,
ordered from most important to least important.

สรุป Tacit Knowledge ที่ดึงได้: 10 องค์ประกอบของเว็บที่ดี เรียงจากสำคัญที่สุด

1. ทำให้ผู้ใช้ทำสิ่งสำคัญสำเร็จได้  
   เริ่มจากรู้ว่าใครจำเป็นต้องใช้เว็บที่สุด และถ้าเขาทำอะไรไม่สำเร็จจะปิดเว็บทันที

2. หน้าแรกต้องเข้าใจทันทีและรู้ว่าต้องไปต่ออย่างไร  
   ผู้ใช้ต้องรู้ว่าเว็บคืออะไร และปุ่มหรือขั้นตอนถัดไปอยู่ตรงไหน โดยเฉพาะบนมือถือ

3. ลดการคิดด้วยการแสดงเฉพาะข้อมูลที่จำเป็นในจังหวะนั้น  
   ข้อมูลรองซ่อนไว้ แต่ต้องค้นเจอได้ง่าย

4. จัดลำดับความสำคัญตามอุปกรณ์  
   Desktop เน้นเห็นภาพรวมครบ ส่วน Mobile เน้นเรียงสิ่งที่ต้องทำก่อน–หลัง

5. ปุ่มหลักต้องเด่น หาเจอง่าย และคงตำแหน่ง/รูปแบบสม่ำเสมอ  
   ผู้ใช้ไม่ควรต้องกวาดหา หรือเดาว่าปุ่มทำงานอยู่ตรงไหน

6. ใช้สีอย่างมีหน้าที่และเข้าถึงได้  
   ใช้กฎ 60–30–10 คุมโทนให้อ่านง่าย แล้วใช้สีตัดกันเฉพาะ CTA หรือจุดสำคัญ พร้อมข้อความ ไอคอน และ contrast ที่ชัดเจน

7. Layout ต้องพาสายตาจาก “เข้าใจ” → “อยากได้” → “กดทำต่อ”  
   ช่องไฟ แนวจัดวาง และลำดับเนื้อหาต้องสะอาด ไม่แน่น ไม่เอียง และไม่เว้นระยะแบบไร้ระบบ

8. รูปภาพต้องช่วยให้เข้าใจและสร้างความมั่นใจ  
   รูปที่ดีต้องบอกได้ทันทีว่าสินค้าหรือบริการคืออะไร ใช้อย่างไร และน่าเชื่อถือพอที่จะตัดสินใจ ไม่ใช่แค่รูปสวยเกะกะ

9. ใช้ Design System เพื่อคุมความสม่ำเสมอ  
   โครงสร้าง ปุ่ม และลำดับหัวข้อต้องเป๊ะเหมือนกันทั้งเว็บ ขณะที่รายละเอียดหรือลูกเล่นปรับเปลี่ยนได้ตามบริบท

10. ทดสอบกับผู้ใช้จริงและปรับจากข้อมูล  
   สังเกตว่าผู้ใช้กดได้ลื่นหรือเมาส์วน/เลื่อนซ้ำ ดู Conversion, Bounce rate และเวลาทำรายการ แล้วแก้จุดที่คนหลุดมากก่อน โดยเริ่มจากข้อความและปุ่มที่แก้ง่ายแต่ส่งผลเร็ว
